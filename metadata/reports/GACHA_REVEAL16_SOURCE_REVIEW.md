# 가챠 연출 원본 5장 검수

기존 `gacha16.png`, `cards16.png`, `fxbig16.png`를 직접 열어 구성과 색을 확인했습니다. 이미 확인한 `parkprops16.png`의 갈색 외곽선과 재질도 기계 제작에 참조했습니다. 최종 PNG 5장을 각각 직접 확인했으며 제작/수정은 이미지 도구로 수행했습니다.

## 확인한 구성

- 기계: 3열×6행. 열은 대기·기울어진 흔들림·배출, 행은 봄·여름·가을·겨울 동물 기계와 직원·우리 기계입니다. 여름은 하늘색, 겨울은 흰색/빨강과 작은 리스입니다. 동물 네 종류의 본체는 같은 모양을 바탕으로 했습니다. 직원은 ID 카드, 우리는 설계도 두루마리가 배출됩니다.
- 캡슐: 회색·초록·파랑·보라·금·파스텔 무지개 순서의 6행, 닫힘·흔들림·균열·열림 4열입니다. 아래 반쪽은 연한 파랑/흰색 면으로 유리를 표현하며 실제 투명 알파가 아닙니다. 열린 상태의 두 반쪽과 사이 빛을 확인했습니다.
- FX: 여섯 등급의 기둥과 속이 빈 폭발 링, 4각 반짝임·5각 별·색종이·햇살·연기·하트 불꽃 순서입니다. 기둥과 링 모두 회색부터 시작해 무지개까지 여섯 종류입니다.
- 카드: 4열×2행. 회색·초록·파랑·보라 동물 앞면 / 금색 동물 앞면·크림 발바닥 뒷면·네이비 직원·노랑/검정 우리 앞면입니다. 앞면 그림창과 이름칸은 비웠으며, 우리 카드 그림창만 요청대로 파란 격자입니다. 보라 카드에는 은색 장식을 사용했습니다.
- 컷인: 위쪽 금색 광선/구름/반짝임, 아래쪽 보라/은색 광선/별입니다. 두 배너의 끝을 비스듬하게 만들었습니다. 최초 결과의 부드러운 광선 음영을 줄이도록 한 번 수정했습니다.

## 판정: HOLD

1. 기계·캡슐은 요청한 **1024×1536**, 컷인은 **1536×1024**입니다. FX는 **1448×1086**으로 요청 **1536×1152**와 다르고, 카드는 **1254×1254**로 요청 **1024×1024**와 다릅니다.
2. 5장 모두 지정 38색 밖 중간색과 배경 마젠타의 변화가 있습니다. 정확한 네이티브 격자와 1픽셀 갈색 외곽선, 균일한 사각 아트 픽셀을 충족한 완성본으로 판정하지 않습니다.
3. 컷인 색 면을 편집했지만 광선/구름/별 내부에 색 변화가 남아 있습니다. 완전한 단색 면과 2~3개 색 띠 조건은 확정되지 않았습니다.
4. 네 동물 기계의 본체 크기·프레임별 중심/바닥 피벗·내부 캡슐 튀는 동작은 정밀 검증하지 않았습니다. 직원 기계의 돔에는 ID 카드 모양 뒤에 일반 둥근 캡슐 하나가 남아 있습니다.
5. 등급별 캡슐의 표시 지름과 열린 두 반쪽 간격이 정확히 같다고 인증하지 않습니다. 균열과 배출 효과는 정지 시트에서 확인했으며 순차 재생과 동작 연결은 미검증입니다.
6. 카드 전체 경계와 빈 그림창/이름칸의 정확한 공통 좌표, 목표 48×64 및 그림창 32×32 규격은 미검증입니다. 컷인 배너의 목표 256×80 네이티브 크기/비율도 확정하지 않았습니다.
7. 투명 배경 추출·아틀라스 좌표·게임의 실제 뽑기 연출에 연결하는 작업은 하지 않았습니다. 이미지 내부의 글자/숫자 없음은 육안 확인이며 자동 문자 검사는 아닙니다.

`tools/audit_gacha_reveal16_sources.py`는 PNG를 변경하지 않고 읽어 크기·색상·배경 테두리·해시를 기록합니다. 70칸은 명세 기준 요청 순서표(기계 18 + 캡슐 24 + FX 18 + 카드 8 + 배너 2)이며 70개 고유 캐릭터나 검증된 애니메이션 수가 아닙니다.

신규 카드 파일은 `assets/spritesheets16/gacha-reveal/cards/cards16.png`입니다. 기존 카드와 기존 게임·ZIP은 보존했습니다. 모든 저장 PNG는 이미지 도구 최종 출력과 바이트가 같습니다.
