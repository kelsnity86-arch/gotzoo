# 입구 게이트 원본 3장 검수

원문을 별도 보존하고 게이트·부속품·계절 장식 순서로 제작했습니다. 기존 WORLD의 건물·철/금 울타리를 직접 열어 스타일을 참고했으며, 부속품 제작에는 새 `gate16.png`를 참조 이미지로 사용했습니다.

## 직접 확인한 내용

- 네 입구는 목재·돌·벽돌/녹색 철·대리석/금으로 구분됩니다. 열린 문과 가운데 마젠타 통로, 왼쪽 기둥 매표창, 빈 간판이 있습니다. 금색 단계에는 왼쪽 사자와 오른쪽 코끼리 조각을 확인했습니다.
- 부속품은 행별 4재질, 열별 벽·끝기둥·매표소·회전문·빈 깃발입니다. 처음 생성된 벽에 붙어 있던 큰 끝기둥과 화분을 제거해 연속 벽 조각으로 수정했습니다.
- 계절 장식 위쪽은 봄꽃·여름 깃발/꽃·단풍/호박·겨울 솔가지/조명/리스입니다. 아래쪽은 기둥 양쪽용 한 쌍씩입니다. 게이트 본체나 장식 뒤 패널은 넣지 않았습니다.
- 모든 최종 PNG를 직접 확인했고 이미지 도구 출력 파일과 바이트가 같은 상태로 저장했습니다. 감사 도구는 PNG를 읽어 크기·색상·해시만 검사합니다.

## 미충족·미검증 항목

**정확한 픽셀 자산·게임 사용 판정은 HOLD입니다.**

1. 실제 크기는 게이트 1254×1254, 부속품 1373×1145, 계절 장식 1774×887이며 모두 요청과 다릅니다.
2. 지정 38색 밖의 중간색과 마젠타의 미세한 변화가 있습니다. 정확한 네이티브 크기와 1픽셀 갈색 외곽선, 완전히 단색인 그림자는 확정하지 않았습니다.
3. 네 게이트의 외형 크기는 비슷하게 배치했지만 동일한 96×88 격자, 정확히 같은 통로 폭·기둥 간격·교체 피벗을 검증하지 않았습니다. 현 상태를 그대로 서로 교체 가능한 게임 자산으로 판정하지 않습니다.
4. 벽의 큰 끝기둥은 제거했지만 목표 32픽셀 폭, 약 28픽셀 높이, 좌우 경계의 반복 이음매는 네이티브 재구성과 조립 검수가 필요합니다.
5. 계절 가랜드의 96픽셀 폭과 아래 장식의 각 20×20 크기, 네 단계 입구 위 합성 위치는 미검증입니다. 마젠타 배경 PNG이며 투명 오버레이를 추출하지 않았습니다.

카탈로그의 행/열은 요청 순서표이며 실제 추출 좌표가 아닙니다. 기존 게임과 기존 ZIP은 교체하지 않았습니다.
