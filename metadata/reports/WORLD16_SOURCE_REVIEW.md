# 동물원 환경 13장 생성 원본 검수

검수 대상은 관람객 4계절, 직원, 타일 4계절, 울타리, 장식 2장, 시설 1장입니다. 이미지 생성 도구로 각 시트를 제작했고, 계절 동일성이 필요한 관람객과 타일에는 봄 시트를 참조 이미지로 사용했습니다.

## 확인한 항목

- PNG 13장이 정상적으로 열리며, 전체 파일 해시가 서로 다릅니다.
- 모든 시트를 직접 열어 행·열 수와 항목 순서를 확인했습니다. 관람객 각 32칸, 직원 20칸, 타일 각 16칸, 울타리 48칸, 장식 각 24칸, 시설/입구 10칸입니다.
- 이미지에 설명문·파일명·셀 번호·격자선은 없습니다. 시설의 간판은 빈 상태이며 진료소는 녹색 십자입니다.
- 봄의 보행 자세 보완, 가을 할머니 A/B 치마 색 통일, 겨울 타일의 봄꽃 제거를 이미지 편집 도구로 수행했습니다.
- 저장한 PNG는 최종 이미지 도구 출력과 같은 바이트입니다. Python 검사는 파일을 읽어 크기·색상·해시를 측정할 뿐 이미지 픽셀을 변경하지 않습니다.

## 합격으로 표시하지 않은 항목

**정확한 픽셀 규격과 게임 동작 판정은 HOLD입니다.** 시트 크기 일치 또는 원본 13장 생성만으로 이 판정을 바꾸지 않습니다.

1. 네이티브 16×24/16×16/32×32/48×32 격자가 확정되지 않았고, 개별 프레임 PNG도 추출하지 않았습니다.
2. 38색 팔레트와 정확한 #FF00FF 배경을 만족하지 못합니다. 생성 결과에는 중간색이 있습니다.
3. 타일 4장의 실제 크기는 1254×1254, 울타리는 1774×887입니다. 그 밖의 8장은 요청한 캔버스 크기와 일치합니다.
4. 사람의 일부 A/B는 다리 실루엣 차이가 작습니다. 서로 다른 이미지라는 사실은 좌우 발 교대 또는 자연스러운 2프레임 보행을 증명하지 않습니다. 반복 재생 QA와 필요한 포즈 수정이 남아 있습니다.
5. 바닥의 반복 이음매와 울타리의 접점 정렬, 오목한 안쪽 모서리와 바깥 모서리의 실제 연결 기능은 검증되지 않았습니다. 16×16에 맞춘 뒤 조립 검수가 필요합니다.
6. 전체 계절 캐릭터의 동일성은 참조 이미지를 통한 시각 검토이며, 모든 얼굴·체형 픽셀이 같다고 판정하지 않았습니다.

사용자가 요청한 분류와 원본 전달은 완료 대상이고, 위 항목은 후속 픽셀 제작·동작 검수 대상입니다. 현재 게임의 정상 코드를 바꾸거나 이 원본을 자동 연결하지 않았습니다.
