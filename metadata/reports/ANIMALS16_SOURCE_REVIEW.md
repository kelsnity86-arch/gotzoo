# 동물 300종 이미지 생성 원본 검수

검수 기준: 사용자가 직접 보낸 12장 명세. 31장 전체가 아니라 동물 300종에 해당하는 이번 묶음입니다.

## 확인한 내용

- `animals16_01.png` ~ `animals16_12.png` 12장의 PNG가 정상적으로 열립니다.
- 12장 모두 직접 보면서 5행 × 5열과 사용자 목록을 대조했습니다. 시트 순서는 상시 250종, 봄·여름 25종, 가을·겨울 25종입니다.
- 원본 파일은 중복이 없고, 파일 이름·등급·계절·행/열 순서표를 별도 JSON에 기록했습니다.
- 이미지 안에 동물 이름, 번호, 캡션, 격자선을 넣지 않았습니다.
- 원본 이미지에 코드로 리사이즈·팔레트 변환·스프라이트 추출을 적용하지 않았습니다.

## 미충족 항목 — 정확한 픽셀 규격 판정은 HOLD

| 항목 | 요청 | 확인된 결과 |
| --- | --- | --- |
| 시트 캔버스 | 1024×1024 | 12장 모두 1254×1254 |
| 네이티브 격자 | 동물당 16×16 | 생성 원본에 엄밀한 격자가 보장되지 않음. 16×16 개별 PNG 없음 |
| 팔레트 | 지정 38색 + 마젠타 | 경계와 채색에 지정 색 밖의 중간색 있음 |
| 배경 | 정확한 #FF00FF 단색 | 마젠타로 보이지만 실제 RGB는 미세하게 다름 |
| 외곽선·표시 방향 | 네이티브 1px, 왼쪽 3/4 | 원본에서 네이티브 두께를 확정할 수 없고 일부는 정면에 가까움 |

따라서 **이미지 생성 원본 전달**과 **게임에 바로 넣을 수 있는 엄밀한 픽셀 자산 완성**을 구분합니다. 후자는 완료되지 않았습니다. 이 검수를 상업용 또는 16×16 완성 PASS로 해석하면 안 됩니다.

다음 제작 단계에는 개별 동물 분리, 정확한 16×16 형태 정리, 38색 팔레트와 배경 정리, 원본 기준 외곽선·신체·방향 검수가 필요합니다. 자동 축소만으로 세부 모양을 유지할 수 있다고 보증하지 않습니다.

기계적으로 측정한 값은 `ANIMALS16_SOURCE_AUDIT.json`에 있습니다. `python tools/audit_animals16_sources.py`로 PNG를 바꾸지 않고 다시 확인할 수 있습니다.
