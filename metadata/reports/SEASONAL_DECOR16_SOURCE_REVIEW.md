# 사계절 장식 원본 4장 검수

작업 전 저장소의 `assets/spritesheets16/world-life/park-props/parkprops16.png`를 직접 열었습니다. 둥근 나무 수관, 따뜻한 목재, 3/4 시점, 왼쪽 위 조명과 오른쪽 아래 그림자를 기준으로 사계절 장식을 순서대로 생성했습니다. 각 최종 시트를 직접 열어 12개 배치와 전체 실루엣을 확인했습니다.

## 확인한 결과

- 봄: 벚나무와 꽃 소품, 소풍 매트/바구니, 짧은 지지대의 연, 분홍 등, 화분대, 새집, 물뿌리개, 잉어 깃발, 그네와 나비 덤불이 지정 순서에 있습니다. 첫 결과의 3:2 화면을 이미지 편집 도구로 2:1에 재배치했습니다.
- 여름: 파라솔·물놀이 소품과 수박 가판, 작은 풍경, 붉은 히비스커스, 휴식 의자, 모래에 선 서핑보드, 분리된 물방울 스프링클러, 아이스크림 카트, 구명환과 야자수입니다. 가판 간판에는 글자 대신 빈 판이나 아이스크림 그림만 있습니다.
- 가을: 단풍과 은행나무, 웃는 허수아비, 일반 호박 더미와 별도 호박등, 건초, 감나무, 수확 바구니, 낙엽과 손수레, 코스모스, 둥근 보름달 등입니다. 계절 나무 세 종류를 색과 잎/열매로 구분했습니다.
- 겨울: 눈사람, 장식 트리와 별도 눈 소나무, 이글루, 썰매, 백조 형태 얼음 조각, 선물, 사탕 지팡이, 눈뭉치, 통나무 불, 열린 전구 아치와 코코아 가판입니다. 얼음/불/전구는 흐린 광원 효과 없이 면과 점으로 표현했습니다. 코코아 간판은 컵 그림입니다.
- 최종 네 시트는 모두 6열×2행이며 총 48개 요청 셀입니다. 큰 배경 장면이나 격자선·문자를 넣지 않았습니다. 작은 품목과 나무의 표시 크기를 다르게 두었습니다.

## 미완료 항목 — HOLD

1. 실제 PNG는 네 장 모두 **1774×887**, 요청은 **1536×768**입니다. 2:1 비율은 맞지만 픽셀 크기는 다릅니다.
2. 지정 38색 밖 중간색과 정확한 `#FF00FF`가 아닌 배경 픽셀이 있습니다. 균일한 사각 아트 픽셀·1픽셀 `#2b1d14` 외곽선·완전한 단색 그림자는 확정하지 않았습니다.
3. 목표인 약 32×40 아트 픽셀, 나무 최대 40×48 크기에 맞춘 네이티브 원본이 아닙니다. 일부 작은 소품의 세부선과 음영은 목표 해상도보다 촘촘합니다.
4. 시트에서 접지 높이를 맞췄지만 개별 자산 추출 후 기준선·바닥 점유 면적·피벗의 정확한 일치는 미검증입니다. 모든 품목의 실제 게임 크기와 서로 간 비율을 인증하지 않습니다.
5. 투명 배경 추출, 실제 공원 타일/방문객과의 합성, 게임에서 1× 표시 검수는 수행하지 않았습니다. 생성 원본 전달과 게임 사용 승인 판정을 구분합니다.
