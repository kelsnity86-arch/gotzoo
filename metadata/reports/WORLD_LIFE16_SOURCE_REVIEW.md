# WORLD 아트 11장 생성 원본 검수

원문은 `docs/briefs/world-life16-original-request.txt`에 보존했습니다. 이 묶음은 기존 WORLD 13장과 별도의 요청입니다. 새 갈색 외곽선·좌상단 광원·차분한 바닥, 정면 관람객과 왼쪽 직원 기준을 적용해 제작했습니다. 게임 코드와 기존 원본을 교체하지 않았습니다.

## 직접 확인 및 보완

- 11장을 순서대로 생성해 직접 확인했습니다. 요청 배치의 칸 수는 16/4/24/4/4/36/18/18/32/20/24, 합계 200입니다. 카탈로그 칸 수는 명세를 펼친 값이며 자동 영상 인식 결과가 아닙니다.
- 잔디는 4계절 4변형, 서식지 바닥은 6종 4변형입니다. 바닥은 외곽선 없는 사각형으로 표현됐습니다. 길에는 일반/겨울과 사각/중앙 마젠타 구멍 패치가 있습니다.
- 울타리는 바닥 없이 사각과 십자 둘레만 그렸습니다. 목재·돌 시트를 참조해 철·금 소재로 편집하여 형태를 이어갔습니다. 십자 내부와 네 모서리 바깥은 마젠타입니다.
- 우리 소품 36칸은 잠자리·물·먹이·놀이·식물·바위 순서입니다. 공원 소품 18칸에는 빈 벤치와 빈 방향 표지판이 있습니다.
- 건물 6종은 위에서 아래로 3단계 커집니다. 간식점·화장실·곰 사진판·분수·퍼걸러·진료소의 색과 소재를 유지했고, 사진판 얼굴 구멍과 간판은 비워뒀습니다.
- 관람객은 4명×8행동의 정면 모습입니다. 첫 결과의 앉은 여성에서 빠진 포니테일을 복원하고 앉은 자세의 외형을 보완했습니다. 스마트폰은 뒷면이 보이고 앉은 자세에는 의자를 그리지 않았습니다.
- 직원은 기존 `world/staff/staff16.png`를 참조해 얼굴·모자·머리 형태를 이어서 작업했습니다. 수거·급식·깃발·청소·매표·걸레질·호루라기·진료·홍보·저글링이 각각 2프레임입니다. 관리인은 빗자루, 청소원은 대걸레를 사용합니다.
- 생활 효과의 수면 표시가 글자처럼 생성되어 흰 말풍선과 파란 구름 안의 표시를 작은 계단형 기호로 수정했습니다. 물결 링 2개는 어두운 외곽선 없이 표현했습니다.
- 저장한 최종 PNG는 해당 이미지 도구 출력과 바이트 단위로 같습니다. 감사 스크립트는 이미지를 읽기만 하며 픽셀을 변경하지 않습니다.

## 미충족·미검증 항목

**정확한 픽셀 및 런타임 판정: HOLD.** 시각적 구성 확인과 원본 전달을 게임용 완성 판정으로 바꾸지 않습니다.

1. 서식지 바닥과 관람객 행동 2장만 요청 캔버스 크기와 일치합니다. 나머지 9장은 실제 크기가 다릅니다. 정확한 수치는 카탈로그와 파일 감사 결과에 기록했습니다.
2. 38색 밖의 중간색, 마젠타와 그림자 내부의 미세한 색 변화가 있습니다. 동일한 네이티브 픽셀 격자·정수 확대율·1픽셀 갈색 외곽선·완전한 단색 그림자를 충족한다고 판정하지 않았습니다.
3. 잔디와 서식지 바닥의 같은 행끼리 모든 방향으로 자연스럽게 반복되는지는 미검증입니다. 길의 포장 패턴도 16픽셀 주기로 정확히 맞는지 확인하지 않았습니다.
4. 사각/도넛 길과 사각/십자 울타리는 48×48 패치 및 16×16 셀로 재구성·추출해야 합니다. 테두리 두께, 오목/볼록 모서리, 반복 울타리 접점, 뒷면/앞면 구분을 실제 조립으로 검증하지 않았습니다.
5. 건물 단계별 크기 차이는 시각적으로 존재하지만 네이티브 32/40/48 격자와 바닥 피벗은 확정하지 않았습니다. 소품과 기존 캐릭터의 픽셀 밀도·접지·그림자 일관성도 합성 장면 검수가 필요합니다.
6. 관람객의 머리·체형 동일성과 직원의 모든 2프레임 연결, 공통 피벗·재생 시간·반복 동작은 미검증입니다. 관람객 응원 자세는 작은 점프로 표현되므로 발 좌표가 다른 정지 자세와 다릅니다. 실제 배치 앵커는 별도로 설정해야 합니다.
7. 명세에 크기가 명시되지 않은 공원 소품 4개는 카탈로그의 목표 네이티브 크기를 `null`로 두었습니다. 이를 임의의 확정 규격으로 표시하지 않았습니다.
