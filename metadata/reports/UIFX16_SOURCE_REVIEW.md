# 가챠·카드·UI·효과 생성 원본 검수

최종 시트 6장을 직접 열어 항목 구성과 배치를 확인했습니다. 파일 검사 도구는 크기·색·해시를 읽으며 PNG를 수정하지 않습니다. 카탈로그의 칸 수는 사용자의 명세를 펼친 값이며 자동 영상 인식 결과가 아닙니다.

## 직접 확인한 내용

- 가챠: 계절 기계 4종의 정지/기울어진 상태, 회전 손잡이 변화, 닫힘/열림 캡슐 6색을 확인했습니다.
- 채용: 봉투·지원서·책상·돈주머니 5개, 회색/초록/파랑/보라/금색 인장과 도장 각 5개입니다. 지원서에는 글씨 없이 빈 사진 칸이 있습니다.
- 카드: 위 7장, 아래 6장입니다. 아래 6열은 마젠타 빈칸이며 7열에 직원 카드 뒷면이 있습니다. 얼굴 그림 없이 빈 창과 이름 칸을 유지했습니다.
- 아이콘: 8×5 순서로 40개를 확인했습니다. 달력·표지판·티켓에는 글자가 없습니다. X·체크·화살표 등은 요청된 기호입니다.
- 소형 효과: 6×5 순서로 30개입니다. 회전 동전 4장의 폭 변화, 반짝임과 불꽃의 크기 변화, 물고기의 왼쪽 시선, 수면 말풍선의 작은 지그재그를 확인했습니다.
- 대형 효과: 빛기둥 5색, 중간 효과 3개, 계절 리본 4개입니다. 첫 생성의 전설 폭발에 있던 사각 패널을 이미지 편집 도구로 제거해 방사형 광선과 마젠타 빈 공간으로 바꿨습니다.
- 최종 저장 파일은 이미지 도구가 만든 해당 PNG와 바이트 단위로 같습니다. 기존 게임 코드와 기존 자산은 교체하지 않았습니다.

## 미충족·미검증 항목

**정확한 픽셀 규격 및 런타임 판정: HOLD.** 원본 파일 생성 완료와 게임 자산 완성을 구분합니다.

1. `icons16.png`는 실제 1448×1086, `fx16.png`는 1374×1145로 요청 해상도와 다릅니다. 나머지 네 장은 캔버스 크기가 일치합니다.
2. 지정 38색과 정확한 단색 #FF00FF를 충족하지 않습니다. 평면처럼 보이는 내부에도 색상 변동과 중간색이 남아 있습니다. 배경색 하나만 제거하는 방식으로 깨끗한 투명을 보장할 수 없습니다.
3. 네이티브 16×16/24×24/32×32/48×48 등 격자, 동일한 정수 확대율, 모든 외곽선의 #1a1c2c·1픽셀 두께는 확정하지 않았습니다. 일부 인장과 입자는 색 외곽선을 사용하거나 외곽선이 없습니다.
4. 카드 창 20×20, 카드 테두리 2픽셀과 각 효과의 지정 크기는 재구성이 필요합니다. 무지개 오버레이도 현재는 불투명 카드 그림입니다.
5. 프레임 추출·공통 피벗 정렬·개봉/회전/흔들림의 실제 반복 재생은 수행하지 않았습니다. 눈으로 다른 포즈를 확인한 사실만으로 애니메이션 합격을 선언하지 않습니다.

이미지 생성 원본과 입력 명세를 보존해 후속 픽셀 제작에서 기준으로 사용할 수 있도록 분류했습니다. 현재 실행 중인 게임에 자동 연결하지 않았습니다.
