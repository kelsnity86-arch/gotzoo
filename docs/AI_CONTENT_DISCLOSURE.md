# 스팀 AI 콘텐츠 공개 (초안)

스팀 앱 등록의 "콘텐츠 설문 → AI 생성 콘텐츠"에 적을 문안 초안이다. 출시 전에 실제 제작 방식에 맞게 다듬는다.

## 사전 생성 콘텐츠 (Pre-Generated)

> 이 게임의 픽셀 아트(동물, 관람객, 직원, 배경 타일, 소품, 건물, 아이콘, 효과)는 AI 이미지 생성 도구로 만든 원본 시트를 개발자가 직접 잘라 내고, 색과 크기를 다듬고, 게임에 맞게 편집해 사용했습니다. 게임 플레이 중에 새로 생성되는 AI 콘텐츠는 없습니다.

> The pixel art in this game (animals, visitors, staff, ground tiles, props, buildings, icons and effects) was created from source sheets made with AI image generation tools, then cut, color-adjusted, resized and edited by the developer for the game. No AI content is generated while the game is running.

## 확인할 것

- 모든 그림이 기존 게임 · 캐릭터 · 브랜드와 닮지 않았는지 전수 검수 (출시 전).
- 글자 · 로고 · 워터마크가 그림 안에 남아 있지 않은지 확인.
- 실제 돈으로 사는 뽑기 없음 → 확률형 아이템 표시 의무 해당 없음 (방침이 바뀌면 다시 검토).
