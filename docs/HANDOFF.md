## 0. 작업 규칙 (반드시 지킬 것)

1. **구현 전에 계획부터 보여주고, 사용자가 "진행해"라고 하면 그때 만든다.** 아이디어를 말할 때마다 바로 구현하지 않는다. 시안(이미지)도 "시안 만들어줘"라고 할 때만.
2. **묻지 않은 일을 마음대로 하지 않는다.** (예: 다른 세션을 몰래 만들기 금지 — 실제로 이 일로 크게 혼났다.) 확실하지 않은 방법을 "해 보라"고 시키기 전에, 안 될 가능성을 먼저 분명히 말한다.
3. 리뷰할 때는 매번 전부 다시 보지 말고, 확인이 필요한 부분만 본다.
4. **답변은 한국어.** 사용자에게 보이는 게임 UI에 **이모티콘 금지** (이름·글자·도트 그림으로).
5. **연출은 기본값 전부 켜짐.** 줄이기는 설정에서만. OS의 "움직임 줄이기" 설정을 따르지 않는다.

7. 플랫폼: Steam(PC) 우선, 폰은 가로 화면. 최종 목표는 **Unity**.
8. git (gotzoo): 브랜치 `ccr-7df278b9-2e7u30`에 커밋하고 **그 브랜치와 `main` 둘 다** 푸시. main 푸시가 거부되면 `git fetch origin main` → merge → 푸시. 커밋 끝에 아래 두 줄:

## 2. 웹판 현재 상태 (2026-11-13 기준, 커밋 36b2e60 이후)

### 게임 흐름
낮: 관객이 떨어뜨린 동전을 손가락/커서로 쓸어 담기(콤보·피버·황금 동전·동전 더미) → 밤: 뽑기·배치·공사·확장 → 7일째 밤 라이벌 대결 → 1년 별 평가 → 지면 하트 잃음 → 하트 0이면 폐원(데려갈 카드 선택) → 다시 시작(폐원 후 ×2 배속 열림).

### 이번 대화에서 확정·구현된 것
- **동전 줍기**: 동전 그림 사각형 어디든 닿으면 즉시 줍기. 회수 반경은 맵 기준 고정(`COIN_FEEL.reach = 2`), 화면 확대/축소를 따라감. **쓸기 속도 제한 없음**(사용자가 제한 거부). 자석 · 손가락으로 빨려드는 효과는 없앰.
- **동전 수명**: 기본 8초(게임 시간), 최대 20초, 깜빡임 마지막 2초. 동전 오래 남기 +1~4초, 관리인 +1~4초, 쉼터 +1초씩(최대 3). 동전 더미 12초.
- **손맛**: 반투명 도트 반짝이 잔상(A안, 흰·노랑·하늘색, 확대 비율 따라 크기), 손가락 옆 합산 숫자 → 코인 칸으로, 콤보 10/25/50/100 단계 터짐(반짝이·화음·살짝 흔들림), 동전 더미(40초마다 매력 1위 우리 앞, 같은 모양 동전이 우르르 떨어져 쌓임, 쓸면 와르르), 대량 줍기 효과음 간격 정리. 진동은 넣지 않음.
- **황금 동전**: "쓸어 담기(범위)" 업그레이드를 대체. 값 5배, 확률 1/1.5/2/3/4/5%. 전망대 · 이카로스도 황금 동전 확률로.
- **동전 합치기**: 동전 하나에 3개까지, 화면에 250개 넘으면 다 합침.
- **배속**: 첫 폐원 후 ×1/×2 버튼(줌 버튼 옆). ×2는 **전부 2배**(동전 수·수명·피버·더미 포함), **콤보 이어지는 시간만 실제 시간**. 시즌 결과 밤엔 ×1로.
- **뽑기**: "한꺼번에 N회"(가진 코인만큼, 최대 10회, 2회 미만이면 꺼짐). 결과는 흩뿌림(최고 등급 카드 가운데 크게, 나머지 겹쳐 흩어짐) → 한 번 더 누르면 **뽑힌 순서대로** 칸 정렬(모두 같은 크기, 창이 칸에 맞게, 최고 등급은 빛 테두리) → 다시 누르면 닫힘.
- **입장식**: 전설 이상만(클로즈업·띠 배너·징글). 반짝이 동물은 첫 배치 때 반짝임 효과만. 우리 테두리 꾸밈(빛 입자·기둥·월계수 간판)은 유지. 환영한 동물 저장(재시작해도 반복 안 함).
- **화면 전체 연출**: 스포트라이트·계절 색·꽃잎/비·피버 빛이 지도 밖 숲까지.
- **정보 줄**: 숫자·시계가 바뀌어도 흔들리지 않게 칸 고정. 뽑기 게이지 흔들림 → 빛만 깜빡.
- **라이벌 칸**: 이름·숫자 없음. **초록(왼쪽부터 차오름) · 빨강 게이지 + 가운데 고정 흰 선** + 남은 날(D-n) + 최후의 기회 표시.
- **타이틀**: B안 + D1 + 아래 꾸밈(E1). 밤 축제 하늘·꼬마전구·캡슐 불꽃놀이(캡슐이 솟아 열리며 등급 색 불꽃), 로고 위 계절 기계 4대(지금 계절이 더 밝게), 언덕 위 동물원 문(**게임 필드와 같은 배치**: 내 동물원 이름은 문 위 판자, 계절 장식은 문 가운데부터 위, 문 발치 장식, 양옆 매표소·깃대), 나무 줄·회전목마·전망대·아이스크림 가게·분수·등불·울타리·꽃밭·산책길, **동물들이 좌우로 걸어 다님**(도감 높은 등급부터). 계절마다 바뀜.
- **앱 시작 화면**: 하얀 기본 화면 → 게임 색 배경 + 로고(안드로이드 12+는 앱 아이콘).
- **렉 개선**: 뽑기·타이틀 창이 떠 있으면 뒤 필드 안 그림, 악기 잔향·잡음 버퍼 재사용·미리 준비.
- **배경음**: 봄 밤 '꽃잎 자장가'와 겨울 낮 '눈송이 왈츠'만 3/4박자. 4/4 편곡을 들어 봤지만 **원곡 유지로 결정**. 나머지 곡은 모두 4/4.

### 3-1. 주변 배경: "사방을 둘러싸는 도시" (센트럴파크 느낌) — **이게 기준**
- 감상용 '전체' 화면 전용(동전 쓸기용 아님). 평소 플레이 화면은 지금 그대로.
- 카메라: **1~4단계 묶음, 5~8단계 묶음**으로 고정 축소. 같은 묶음 안에서 확장하면 넓어진 땅이 보임. 4→5단계 때 카메라가 쭉 빠지며 도시가 펼쳐지는 연출(제안).
- **담장**: 동물원 사방. **2단계 단위**로 바뀜 (1~2 나무, 3~4 돌담, 5~6 벽돌, 7~8 대리석+금장식). **위쪽 담장은 아치문 기준**(문이 위 담장 가운데에 서서 위로 솟음), 문 위로도 풍경이 보여야 함.
- **도로**: **위쪽 문 앞에만, 한 줄로 화면 왼쪽 끝~오른쪽 끝까지 쭉**. 좌·우·아래엔 도로 없음(담장 바로 바깥부터 풍경). 단계마다 도로 느낌이 다름(1 흙길 … 8 화강암 대로).
- **움직이는 것**: 사람 없음. 차·택시·버스·마차·배·헬기·비행선·열기구·새 등.
- 계절은 덧입히기(봄 벚꽃, 여름 짙은 초록, 가을 단풍, 겨울 눈 지붕), 밤은 창문 불빛.
- GPT 명령서: `docs/briefs/surround-concept16-request.txt` + 레이아웃 3장 `docs/briefs/surround-ref/layout_stage{1,5,8}.png` (실제 화면 비율, 동물원 그대로, 노랑=도로·하늘색=담장·분홍=풍경). 사용자가 만든 시안: `assets/concepts/surround16/` (첫 시안은 비율이 실제 게임과 안 맞아서 레이아웃 방식으로 다시 씀. `layout-guided-drafts`는 사용자가 "원본 픽셀 보존 검사 FAIL/HOLD"로 따로 보관).

### 3-2. 판매 기능 (Unity APK에서 개선된 부분 → 웹판·Unity 기준으로 삼음)
APK 안의 글·설정에서 읽은 내용:
- 동물 판매 값 = 지금 단계 뽑기 1회 값 × 등급 비율 (일반 0.1, 고급 0.2, 희귀 0.4, 영웅 0.75, 전설 1.5), 반짝이 ×2, 코인으로 받음(뽑기에 씀).
- "중복만 판매"(종마다 일반 1마리 남김, 끄면 1마리뿐인 것도 대상), 종별 판매 잠금, 신화(네임드)는 판매 불가, 우리는 보관 중인 것만 판매, 새로 뽑은 동물 자동판매(등급 선택, 처음 나온 종은 제외), 팔아도 도감 유지, 판매 대상 확인 미리보기, 판매 연기 연출, 개별 판매는 카드 상세.
- **미결정**: 합성을 없애고 판매만(A, 추천 — Unity와 같음) vs 둘 다(B). 사용자 답 아직 없음.

### 3-3. Unity로 0부터 옮기기 (계획만 제시, 미결정)
- 원칙: 웹판이 정답, 규칙(순수 C#, 웹판 대조 테스트)과 화면 분리, 기획(판매·주변 도시)을 웹판에 먼저 확정.

## 확정된 게임 규칙
- 조작: 통깡이(플레이어)가 맵을 돌아다니며 야생 통붕이를 흡수한다. 터치 드래그는 가상 조이스틱, PC는 WASD/방향키.

- 시청자 수 = Σ(단계별 마릿수 × 100^단계). 한국식 단위(만·억·조·경·해·자·양·구)로 표시한다.

- 화폐 두 종류:
