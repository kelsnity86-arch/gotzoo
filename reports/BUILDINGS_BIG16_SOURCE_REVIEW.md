# 확대 건물 원본 검토

파일: `assets/spritesheets16/buildings-large/buildings_big16.png`

기준: `assets/spritesheets16/world-life/buildings/buildings16.png` 및 `docs/prompt_buildings_big16.txt`.

기준 이미지와 두 번의 생성 출력을 직접 확인했습니다. 첫 출력은 기준의 3:2 가로 비율과 작은 건물 구조를 지나치게 유지해 최종 파일로 선택하지 않았습니다. 두 번째 출력에서는 정사각형 6×3 배치와 건물의 측면·창문·기단, 퍼골라 깊이와 정면 접근 공간을 보강했습니다.

매점의 빨강/크림 차양과 목재 카운터, 화장실의 두 문과 초록 지붕, 곰 얼굴 구멍, 회색 석재/파란 물 분수, 목재/식물 퍼골라, 크림 벽/초록 십자 진료소가 이어집니다. 18개 칸과 빈 간판은 시각적으로 확인했습니다. 분수·포토존·퍼골라에는 부자연스러운 건물 창문을 넣는 대신 정면 접근 공간과 빈 명패를 사용했습니다.

## 판정

**HOLD.** 실제 PNG는 1254×1254로 요청 1536×1536을 충족하지 못합니다. 332269개의 RGB 색이 검출되어 제한 팔레트·정확한 평면 색·단색 마젠타를 충족하지 못합니다. 정확한 네이티브 격자와 1픽셀 외곽선도 확정하지 않았습니다.

행에 따라 구조와 크기는 커지지만 정확한 48/64/80 네이티브 바운딩박스와 동일 픽셀 배율을 검증한 것은 아닙니다. 26픽셀 방문객과의 게임 내 상대 크기, 모든 문 높이, 픽셀 기준점은 별도 확인이 필요합니다. 대형 행에는 좁은 가로 간격이 있어 자동 균등 분할을 보증하지 않습니다. 전체 실루엣과 간격을 개별 추출 단계에서 확인해야 합니다.

이미지의 재생성·편집은 이미지 생성 도구로만 진행했습니다. 최종 PNG는 바이트 그대로 복사했으며 기존 건물, 게임용 추출 PNG, 렌더러는 수정하지 않았습니다. 목록의 행/열은 요청 칸이며 픽셀 추출 좌표가 아닙니다.
