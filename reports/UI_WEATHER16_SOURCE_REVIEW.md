# UI·날씨 추가 원본 검토

원본 납품: PNG 3장. 요청 칸 96개(40 + 32 + 24). 엄격 픽셀 및 게임 반영 판정: **HOLD**.

## 직접 확인한 항목

기존 `icons16.png`, `icons16_2.png`, `fx_life16.png`를 열어 참고했습니다. 신규 이미지의 8×5, 8×4, 6×4 배열과 행 우선 순서를 눈으로 확인했습니다. 목록·달력·팻말에는 글자나 숫자를 넣지 않았으며, UI의 더하기·빼기·X·체크는 요청된 기호로 사용했습니다.

첫 아이콘 시트는 탭·관리·재화·시간·화면 조작을 배치했습니다. 두 번째는 서식지·계절·등급·직원 직종을 배치했습니다. 빗자루와 대걸레, 확대와 축소, 음성 켜기와 끄기는 서로 다른 실루엣을 사용합니다. 등급별 별의 완전한 동일 실루엣은 픽셀 단위로 검증하지 않았습니다.

날씨 첫 출력에서는 빗줄기가 여러 물방울로 표현됐고 물튀김의 후속 프레임이 더 높았습니다. 이미지 편집으로 한 줄기 빗방울과 더 낮고 넓게 퍼지는 후속 물튀김으로 수정했습니다. 부채꼴 햇빛은 네 방향 반짝임으로 변경했습니다. 반딧불과 조명 웅덩이는 테두리 없는 원형/타원형 색 띠로 표현했습니다. 이것은 네이티브 픽셀이나 애니메이션 합격 판정이 아닙니다.

물튀김 프레임의 동일 기준점, 꽃잎 회전 일관성, 실제 속도 재생과 작은 화면에서의 아이콘 판독성은 별도 확인이 필요합니다. 목록 JSON의 칸은 요청 명세이며 자동 검출 결과나 게임 추출 좌표가 아닙니다. 파일을 세 장 만들었다는 사실과 픽셀 규격 준수는 별개의 판정입니다.
