# 확장 시트 4장 생성 원본 검수

사용자가 지정한 순서대로 `icons16_2.png`, `pengacha16.png`, `fencesdiag16.png`, `incidents16.png`를 생성했습니다. 기존 아이콘·울타리·봄 관람객 시트를 직접 열어 스타일을 확인했습니다. 최종 시트도 직접 확인했으며, 검사 스크립트는 PNG를 읽고 JSON을 만들 뿐 이미지 픽셀은 변경하지 않습니다.

## 직접 확인한 내용

- 확장 아이콘은 8×3 배치입니다. 이익은 동전 위 초록 위쪽 화살표, 손실은 동전 위 빨강 아래쪽 화살표로 구분했습니다. 체크리스트·영수증은 글자 없이 선만 있습니다.
- 우리 뽑기는 첫 행 기계 2포즈·닫힌 상자·열린 상자·도면·망치, 둘째 행 5등급 도면, 셋째 행 먼지 3단계·반짝임 2단계·L형 배치 표시입니다. 기계 손잡이와 기울기, 상자 뚜껑과 나오는 블록을 확인했습니다.
- 대각 울타리는 목재·돌·검은 철·금색 보석 각 4칸입니다. 두 기울기가 교대로 배치되며 바닥 8칸은 사각형으로 채워졌습니다. 마지막 행의 나무/돌 안내판과 금색 명판은 비어 있습니다.
- 사건은 소매치기 5포즈, 말풍선/효과 8개, 파업 직원 4포즈입니다. 첫 결과에서 체포 포즈가 정면에 가까워 왼쪽으로 수정했고, 회복 2단계·호루라기·방패 효과에 붙어 있던 말풍선 배경을 제거했습니다. 직원 팻말은 빈 상태이며 높낮이 변화가 있습니다.
- 모든 최종 파일은 이미지 도구 출력 PNG와 바이트 단위로 같습니다. 기존 원본과 게임 코드에 덮어쓰지 않았습니다.

## 미충족·미검증 항목

**파일 전달과 구성 확인은 완료했지만, 정확한 픽셀 자산 및 게임 동작 판정은 HOLD입니다.**

1. 아이콘과 대각 울타리의 실제 캔버스는 1774×887로 요청한 1536×768과 다릅니다. 나머지 두 장은 1536×1024입니다.
2. 지정 38색 밖의 중간색과 마젠타의 미세한 색 변화가 있습니다. 정수 확대된 네이티브 16×16/16×24 등 격자와 모든 외곽선의 정확한 색·1픽셀 두께는 확정하지 않았습니다.
3. 대각 울타리의 상/하 방향 깊이 차이는 일부 비슷하게 보입니다. 16×16의 정확한 대각 끝점, 직선 울타리와의 접점, 원형·팔각 우리 조립은 검증되지 않았습니다. 그림에 대각선이 있다는 사실만으로 연결성을 합격 처리하지 않습니다.
4. 바닥 8칸은 가장자리까지 채워진 사각 그림이지만, 반복 시 이음매가 없는지는 검증되지 않았습니다. 네이티브 타일 재구성 후 반복 배치 확인이 필요합니다.
5. 걷기/달리기에서 다른 다리 포즈를 확인했지만 발 교대, 얼굴·체형 유지, 공통 피벗, 실제 루프 재생은 미검증입니다. 건설 먼지·반짝임·팻말·불평 효과도 프레임 추출 후 재생 확인이 필요합니다.

원본을 시트 전체 단위로 16×16로 축소하지 마세요. 개별 칸을 기준으로 경계·목표 격자·팔레트·피벗을 확정한 뒤 사용해야 합니다.
