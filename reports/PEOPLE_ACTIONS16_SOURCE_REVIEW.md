# 관람객 모델·사계절 행동·VIP 14장 원본 검수

사용자가 현재 작업 다음으로 요청한 14장을 명령서 순서대로 생성했습니다. 8명 모델 → 봄 보행/행동 → 여름 → 가을 → 겨울 → VIP 순서입니다. 모든 최종 시트를 직접 열어 배치와 주요 포즈를 확인했습니다.

**생성 원본 14장 전달은 완료했지만, 정확한 픽셀 자산과 애니메이션의 최종 판정은 HOLD입니다.** 파일 수 검사를 작화·동일성·보행 PASS로 해석하지 않습니다.

## 구성과 직접 확인한 내용

- 모델 1장: 민준·서아·지우·현·아빠·엄마·할머니·관광객 8명, 위쪽 정면/아래쪽 왼쪽 보행. 민준과 아빠의 머리색을 검정으로 수정한 모델을 후속 참조로 사용했습니다.
- 계절 보행 4장: 각 8열×2행. 봄 보행 아래 행의 뒤쪽 무릎과 발을 수정하고 이 시트를 참조해 여름·가을·겨울 의상을 편집했습니다. 좌향은 보이나 정확한 좌우 다리 교대는 검증 완료가 아닙니다.
- 정면 행동 8장: 계절마다 A는 1~4번, B는 5~8번입니다. 관람·환호·휴대폰 촬영·간식·가리키기·앉기·동전 던지기·실망 순서입니다. 휴대폰 뒤쪽과 카메라 점, 벤치 없이 앞으로 내민 두 발, 별도 동전을 확인했습니다.
- 계절 간식은 봄 아이스크림 콘, 여름 아이스바, 가을 콘도그, 겨울 코코아 컵입니다. 겨울 컵은 입 아래에서 들고 있는 형태이며 연속 음용 애니메이션은 아닙니다.
- 지우의 포니테일, 현의 파란 배낭, 엄마의 번 헤어/가방, 관광객의 모자/카메라를 후속 편집 지침과 참조에 포함했습니다. 정면 행동은 기존 봄 시트를 편집해 계절별 독립 재해석을 줄였습니다.
- VIP 1장: 10열×4행. 금색 신사·강아지 가방을 든 영화배우·마녀 의상 아이·천 유령 의상 아이입니다. 앉은 신사의 누락된 모노클을 복원했습니다. 영화배우의 가방 속 강아지는 전 포즈에서 보입니다.
- 시트 안에 글자·번호·격자선을 넣지 않았습니다. 원본 PNG의 픽셀을 코드로 수정하지 않았고, 이미지 도구 결과와 바이트가 같은 파일을 저장했습니다.

## 미충족·미검증

1. 모델과 보행 4장은 실제 **1774×887**, 요청은 **1536×768**입니다. 행동 8장과 VIP는 요청한 **1536×1024**입니다. 9장 크기 일치, 5장 불일치입니다.
2. 14장 모두 지정 38색 밖 중간색이 있고 배경에도 정확한 `#FF00FF`와 다른 픽셀이 있습니다. 결과는 촘촘한 확대 일러스트에 가까운 부분이 있으며, 정확한 16×26 아트 격자·균일한 사각 픽셀·1픽셀 갈색 외곽선 요건을 충족한 네이티브 자산이 아닙니다.
3. 보행 A/B의 팔다리 위치를 구분했지만 모든 사람의 좌우 다리 정체성과 지지발, 루프 재생을 검증하지 않았습니다. VIP 보행은 두 프레임의 다리 차이가 특히 약합니다. 마녀의 보행 B에서 눈 표정도 변하므로 고정 얼굴 기준을 충족하지 못합니다.
4. 앉은 포즈의 머리 표시 크기, 신발 바닥색, 일부 코트 단추/소매, 겨울 가리키기 포즈의 장갑에는 차이가 남아 있습니다. 정확한 전 프레임 얼굴/체형/복장 동일성 PASS로 판정하지 않습니다.
5. 환호 포즈는 팔을 어깨 위로 든 형태가 많고 큰 점프가 아닙니다. 손가락 방향과 동전 궤적, 컵을 실제로 마시는 연결 동작은 별도 게임 재생 검수가 필요합니다.
6. 네이티브 추출·투명화·프레임 크기/발 피벗 정렬·엔진 애니메이션 연결을 수행하지 않았습니다. 모든 시트에서 같은 기준선과 같은 16×26 크기라고 보증하지 않습니다.

## 파일 검사와 사용 범위

`tools/audit_people_actions16_sources.py`는 PNG 디코딩·크기·색상·해시를 읽고 카탈로그와 검수 JSON을 만듭니다. 이미지를 수정하거나 개별 캐릭터의 의미를 자동 판정하지 않습니다.

카탈로그의 **376칸**은 모델 16 + 보행 64 + 정면 행동 256 + VIP 40이며, 서로 다른 사람 376명이 아닙니다. 행/열은 요청 순서표이고 추출 좌표가 아닙니다. 기존 원본 시트·기존 ZIP·게임 코드는 교체하지 않았습니다. 다른 작업자가 올린 게임 변경은 원격에서 그대로 받아 보존했습니다.
