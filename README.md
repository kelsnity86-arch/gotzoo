# 뽑ZOO

동물 카드를 뽑고 합성해서 동물원을 키우는 웹 게임. 기획: `animal_gacha_zoo_gdd_v02` (기획 0.2) + 변경점(우리 하나에 여러 마리, 2~10장 확률 합성).

- 위쪽 관객존: 관람객이 걷다 멈춰 동전을 던진다. 던지는 순간 기본 수입. 동전은 관객존 바닥에 떨어지고, 동전을 눌러서(업그레이드 '쓸어 담기' 후엔 커서를 대기만 해도)·수거 직원이 주우면 보너스(50%). 60초 넘게 방치하면 깜빡이다 사라진다.
- 아래쪽 동물존: 우리 2개 × 4마리에서 시작해 업그레이드로 우리 10개 × 30마리까지.
- 동물 뽑기 1·5·10회 (첫 1회 무료 일반 확정), 동물만 나옴, 등급 확률 60/25/10/4/1%.
- 직원 뽑기(코인, 동물 뽑기 ×3) 1·5명: 직원 10종(수거 · 사육사 · 안내원 · 관리인 · 매표원 · 청소부 · 경비원 · 수의사 · 홍보 담당 · 공연가) × 등급 5단계, 효과는 등급을 따름. 영웅 특수옵션 1개 · 전설 2개(검소함 · VIP 담당 · 야근 · 인기인 · 말솜씨 · 살림꾼 · 분위기 메이커 · 먹이 장인 · 충성 · 행운). 월급은 뽑을 때 등급 범위에서 랜덤으로 정해져 고정, 배치된 직원만 받음. 해고하면 직원 뽑기 가격의 10~25% 환급.
- 정산: 수입 − 월급 − 유지비(우리 고정비 + 등급별 사료비, 단계별 비용 단위) = 순이익. 빚 허용: 빚이면 뽑기·뽑기권·공사 불가, 빚으로 3일 이어지면 다음 날 직원 파업('충성' 직원 제외).
- 사고: 하루 60% 확률로 소매치기(오늘 수입 8% 손실, 경비원이 막음) 또는 동물 감기(우리 하나 매력 −40%, 수의사가 막음).
- 합성: 같은 등급 2~10장 → 다음 등급, 많이 넣을수록 확률 ↑ (10장 100%), 실패하면 1장 돌려받음.
- 업그레이드: 부지 넓히기 · 관객의 질 · 입장 게이트 · 직원 슬롯 · 쓸어 담기. 진행 단계 승급(최대 8).
- 동물 크기는 등급마다 다르다 (일반 1× → 고급 1.2× → 희귀 1.45× → 영웅 1.75× → 전설 2.2×, 도트가 고르게 기기 픽셀 정수 배로 그림).
- 보관함 '최대 수익 배치': 높은 등급부터 고르고, 같은 서식지·같은 종을 한 우리에 모아 매력도 합이 가장 크게 다시 배치.
- 세로 화면에서는 동물원이 아래 화면 전체를 쓰고, 패널은 아래 탭에서 여는 서랍.
- 확대: 휠 / 두 손가락 벌리기, 확대 중 이동: 마우스로 끌기 / 두 손가락. '전체 보기'로 원래대로.
- 이벤트 손님(70~110초마다 20초): VIP(큰 동전) · 단체 관광버스(관람객 3배) · 소나기(관람객 ↓, 투척액 ↑) · 축제(투척액 2배).
- 오늘 영업 미션: 게임 속 하루마다 3개(관람객 · 직접 줍기 · 오늘 수입 · 먹이 중), 낮에 한 일만 센다. 영업이 끝나면 달성한 건 자동으로 받고(하나 뽑기권 1장, 셋 다 +2장) 못 한 건 사라진다.
- 계절: 라이벌 시즌 1개(7일) = 계절 1개, 봄 → 여름 → 가을 → 겨울, 4시즌 = 1년(겨울을 이기면 1주년 보너스). 제철 서식지 +20%(봄 풀밭 · 여름 물가 · 가을 바위산 · 겨울 설원), 약한 서식지 −15%(여름 설원 · 겨울 사막), 냉난방비(여름 설원 · 겨울 사막 동물 수만큼). 계절 이벤트 12종(벚꽃 축제 · 어린이날 · 꽃가루 · 물놀이 데이 · 장마 · 폭염 · 단풍 축제 · 추석 · 핼러윈 · 크리스마스 · 첫눈 · 한파). 필드에 계절 덧칠과 꽃잎 · 낙엽 · 눈.
- 계절 한정 동물 50종(고급~전설): 고급 이상이 나오면 20% 확률로 그 계절 한정 풀에서. 제철엔 매력 +100%, 같은 우리 +10%.
- 반짝이 변종: 동물 뽑기 1%(합성은 반짝이 재료 1장당 +10%p), 색이 바뀌고 반짝임, 매력 · 규모 1.5배, 반짝이 도감.
- 시너지(우리 하나당 최대 +150%): 조합 세트 16종(사바나 · 극지 · 농장(사료비 −30%) · 동양 신수(투척액 +10%) · 추석 · 산타 썰매 …, 계절 세트는 제철 2배, 시너지 도감), 서식지 단계(3/6/10마리 +10/20/35%), 등급(무지개 +30% · 동급 무리 +15%(일반 +25%) · 왕의 무리 +20%), 계절. 우리를 누르면 발동 중인 시너지와 '1마리 더' 힌트.
- 우리 조각 · 부지: 동물존은 블록 격자 부지(8×4칸에서 '부지 넓히기'로 20×9칸까지). 우리는 우리 뽑기(코인, 동물 뽑기 ×2)로 얻는 테트리스 같은 조각 25종(일반 4칸 테트로미노 → 전설 원형 무대 · 팔각 대정원 등). 서식지는 카드에 정해져 있고 같은 서식지 동물 +10~40%(등급별), 영웅 옵션 1 · 전설 옵션 2(인기 우리 · 알뜰 사료 · 포토 스폿 · 명소 · 먹이 정원 · 사계절 정원). 블록 1칸 = 1.6마리, 유지비는 칸 수만큼. '자동 배치(가장 효율 좋게)' 또는 직접 놓기(회전 · 미리 보기), 우리를 눌러 치우기, 같은 등급 2~10개 합성. 빈 칸은 풀밭 · 나무 · 꽃. 동물은 조각 모양 안에서만 다닌다. 예전 저장은 사각 조각으로 옮겨 동물을 그대로 둔다.
- 16px 그래픽: GPT 원본 31장(assets/spritesheets16)을 tools/slice16.py로 원래 도트 격자대로 잘라 assets/sprites16에 둔다(동물 300 · 계절 관람객 · 직원 · 계절 타일 · 울타리 · 아이콘 · 효과). 원본이 16px보다 촘촘해서(동물 약 24~30px) 그 해상도 그대로 쓰고, 화면에서는 등급 크기에 맞춰 정수 배(작으면 부드럽게 축소)로 그린다. 바닥은 계절별 타일, 관람객은 계절 옷.
- 동물 300종: 상시 250(일반 80 · 고급 65 · 희귀 55 · 영웅 32 · 전설 18) + 계절 한정 50. 조합 세트에 사신수 · 빙하기 · 심해 · 북극 바다 · 영장류 추가(21종).
- 시설 · 꾸미기(동물원 > 시설 / 꾸미기, 짓기는 밤에만): 시설 6종(매점 투척액 +8% · 화장실 최대 관람객 +10% · 벤치 동전 +15초 · 분수 붙은 우리 +10% · 포토존 관람객 +8% · 동물병원 감기 50% 막기, 겹치면 최대치까지, 매일 유지비, 규모 +15)과 계절 소품 48종(그 계절 12종만 판매, 붙은 우리 +4%, 제철 2배, 규모 +5)을 부지 1칸에 놓는다. 누르면 치워서 보관함으로. 울타리 · 입구 꾸미기 4단계(나무 → 돌 → 철 → 황금, 모든 동물 +3%씩, 울타리와 입구 게이트 그림이 바뀜). 자동 배치는 시설 칸을 피한다.
- 화면: 큰 탭 5개(뽑기[동물·직원·우리] · 동물원 · 카드[동물(보관함/합성)·직원·우리] · 운영[업그레이드·직원 배치·돈] · 기록[미션·도감·시너지·라이벌]), 받을 게 있으면 탭에 빨간 점. HUD는 코인 · 분당 수입 · 시계 · 라이벌 규모만.
- 라이벌 동물원: 7일 시즌마다 라이벌 하나(냥냥랜드 → 판다파크 → …). 시즌 마지막 날 동물원 규모(전시 동물 등급 점수 + 배치 직원 등급 점수 + 업그레이드 레벨 × 10 − 빚 감점)가 라이벌보다 크면 승리(코인 + 뽑기권), 작으면 폐원. 폐원하면 동물원·코인·카드는 처음부터, 도감·최고 기록은 남는다. 라이벌 규모는 시뮬레이션 봇 기준으로 맞춤(봇은 보통 4~9시즌 버팀).
- 도감 보상(등급·서식지별로 다 모으면 코인 + 영구 보너스).
- 낮/밤: 낮 3분 영업(마지막 20초는 저녁, 관람객 퇴장) → 영업 끝 정산창 → 밤 정비(시간 제한 없음). 시설 업그레이드는 밤에만, 뽑기·배치·합성은 언제나. 정비를 마치고 '개장하기'로 다음 날. 밤엔 바닥 동전을 관리인이 있으면 절반 회수, 없으면 사라짐.
- 자리 비움 수익: 닫았다 열면 평소 기본 수입의 30% (최대 8시간).
- 타이틀 화면, 설정(효과음 크기·끄기, 저장 코드로 기기 옮기기, 초기화), 전설 등장 연출, 합성 캡슐 연출, 동물 말풍선.

## 개발
```
npm install
npm run dev        # 개발 서버
npm test           # 규칙 테스트
SIM=economy SIM_MIN=120 npm run sim   # 경제 시뮬레이션 (봇이 2시간 플레이)
npm run build:artifact   # 한 파일 배포본 dist-artifact/bbopzoo.html
```

## 그림
`assets/sprites/**`의 GPT 원본 PNG(원본 픽셀 크기, 배경 #FF00FF)를 불러와 배경색을 투명으로 바꿔 쓴다 (`src/render/sprites.ts`).
- 동물: 시트 번호·칸 순서대로 `animal_000`~`099` (= `src/data/animals.ts` 순서)
- 사람: 1~8 관람객 `person_00`~`07`, 9 수거 직원, 10 사육사 / 동전: 효과 1~4
- 타일·아이콘·카드·가챠·UI: `tiles_01`처럼 폴더 이름 + 번호. 필드 바탕(잔디·길·울타리·서식지 바닥·나무·소품)과 뽑기 기계 연출에 쓴다.
그림이 없는 항목은 코드로 그린 임시 도트로 대신한다.
