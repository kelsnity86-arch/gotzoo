## 남아 있는 규격·동작 검수

- 관람객·직원의 16×24, 타일·울타리의 16×16, 소품의 32×32, 입구의 48×32 네이티브 격자를 확정한 개별 PNG는 없습니다.
- 지정 38색 밖의 색과 미세한 배경색 변화가 있습니다. 정확한 #FF00FF 및 안티앨리어싱 없는 픽셀로 정리해야 합니다.
- 계절 타일 4장은 요청 1024×1024와 다르고, 울타리는 요청 1536×768과 다릅니다. 나머지 8장은 요청 캔버스 크기와 일치합니다.
- 사람 A/B는 일부 쌍의 다리 실루엣이 비슷합니다. 발의 교대와 실제 반복 재생을 검수·보완해야 합니다.
- 바닥 타일의 양쪽 가장자리 반복 연결과 울타리의 접점, 안쪽/바깥쪽 모서리 구분은 게임용으로 검증되지 않았습니다.
